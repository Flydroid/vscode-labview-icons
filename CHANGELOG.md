## [1.0.0] - 2026-10-12

### Added

- File icons for `.vi`, `.vim`, `.vit`, `.ctl`, `.ctt`, `.xctl`, `.lvclass`, `.lvlib`, `.lvlibp`, `.llb`, `.lvproj`, `.lvsc`, `.xnode`, `.rtm`, `.mnu`, `.lvbitx`, `.lvlps`, `.aliases`, `.tdms`, `.tdms_index`, `.lvm`.
- Class-member VI icon for VIs owned by a `.lvclass`, through managed `files.associations` entries.
- XML highlighting for XML-based LabVIEW files. INI highlighting for `.aliases` and `.lvlps`.
